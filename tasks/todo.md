# 関数ビジュアライザー実装計画

入力した関数 f(x) とその導関数 f'(x) を 3Blue1Brown 風に同時可視化し、
x を動かすアニメーション・積分モード・3D 曲面モードを備える Web アプリ。

## スタック
- Vite + React + TypeScript / math.js(パース・記号微分)/ KaTeX(数式表示)
- 2D: Canvas 自前レンダラ(グロー・接線・面積塗り・ズーム/パン)
- 3D: Three.js(曲面 + 勾配ベクトル + 接平面 + OrbitControls)
- テスト: Vitest(数式エンジン)

- ユニットテスト 14 件すべて成功(パース / 微分 / 偏微分 / 2 階微分 / 数値積分 / 補間)
- `tsc -b` 型チェック・`npm run build` 本番ビルドともに成功

  コンソールエラーなし、各モードのスクリーンショットを `screenshots/` に保存
- 値の検算: f'(1.64)=0.70、F(3.92)=4.29(=x⁴/12−x²)、∂f/∂x=cos(y)cos(x)=0.48 など一致

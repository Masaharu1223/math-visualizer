# 関数ビジュアライザー実装計画

入力した関数 f(x) とその導関数 f'(x) を 3Blue1Brown 風に同時可視化し、
x を動かすアニメーション・積分モード・3D 曲面モードを備える Web アプリ。

## 現在のタスク: 媒介変数曲線の算術演算・描画ロジック

### 仕様
- `x(t)` と `y(t)` を math.js 構文で入力し、変数 `t` のみを許可してパースする。
- `t` の範囲をプリセットごとに持たせ、曲線を `Samples` として生成して既存 Canvas レンダラに渡す。
- 入力途中の壊れた式はエラー表示し、描画不能な式ではクラッシュさせない。
- `cos(t), sin(t)` の円、カージオイド、リサージュなどをサンプリングして実際に描画する。
- `.claude/` 配下の未追跡コピーはコミット対象にしない。
